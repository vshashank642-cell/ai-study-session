# AI Study Session

An AI-powered study session generator for students.

## Product direction

Turn a student's topic, available study time, level, and goals into a focused study session:

1. Learn the essentials
2. Practice targeted questions
3. Test understanding
4. Fix weak areas
5. Finish with active recall

## Status

Early MVP — frontend foundation is being built first. AI provider, authentication, database, analytics, rate limiting, and production deployment will be added as the product requirements are finalized.

## Development

This project is intended to be deployed with Vercel and will keep AI credentials server-side through environment variables.
